Ada Chess Table

A chess environment connecting physical-board interaction, authoritative game state, engines, and review.

The question

Physical moves, software state, and the companion's explanation need to agree about the same game.

How we approach it

Kit directs the experience and tests physical-board workflows. Ada assists with interfaces, game-state integration, move handling, and review tools.

What is available

  • An owner-operated local chess table and documented physical-board workflows.
  • Game state used as the authority before moves and analysis.
  • A distinction between companion reasoning, engine assistance, and recorded review.

What the evidence supports

The local table and public chess repositories have distinct histories. A reviewed public source package for this exact application has not been linked in this edition.

A useful next step

Prepare a clean game demonstration with a reproducible setup and explicit board support.
